# 📖 درباره پروژه

**Electronics Business Website** یک وب‌سایت فروشگاه وسایل الکترونیک فارسی است که بیشتر به تیزر محصول نزدیک است تا به یک کاتالوگ ثابت.

کار اصلی صفحه دیداری است: پری‌لودر، نشانگر سفارشی، نوار پیشرفت اسکرول، ناوبری مرحله‌ها، صحنهٔ سه‌بعدی لپ‌تاپ و کانفیگوراتور که با عوض شدن گزینه جمع را عوض می‌کند.

کتابخانه‌ها از CDN می‌آیند. بک‌اند و مرحلهٔ بیلد وجود ندارد.

> **جمله کوتاه:** *یک وب‌سایت سینمایی فروشگاه الکترونیک فارسی با حرکت اسکرول، پیش‌نمایش سه‌بعدی محصول و پیکربندی زنده.*

---

# 🚀 چرا این وب‌سایت؟

صفحهٔ فروشگاه می‌تواند فقط مشخصات را بنویسد، یا خود دستگاه را حرکت بدهد.

این پروژه روی مسیر دوم ایستاده است:

- حرکت به اسکرول وصل است، نه فقط به کلیک
- درب لپ‌تاپ با پایین آمدن صفحه بالا می‌آید
- ناوبری در دسترس می‌ماند و صحنه را نمی‌پوشاند
- بازدیدکننده می‌تواند قطعات را بچیند و قیمت را همان‌جا ببیند
- حس سینمایی از ابتدا تا انتهای صفحه حفظ می‌شود

---

# ✨ قابلیت‌ها

- 🎬 پری‌لودر تمام‌صفحه با درصد آماده شدن
- 🖱️ نشانگر سفارشی و لایهٔ دانهٔ فیلم
- 📍 ناوبری بین بخش‌های صفحه
- 📊 خط پیشرفت اسکرول در بالای صفحه
- 💻 پیش‌نمایش سه‌بعدی لپ‌تاپ با دربی که هنگام اسکرول باز می‌شود
- ✨ درخشش صفحه و ذرات اطراف صحنهٔ اصلی
- ⚖️ مقایسهٔ کنار هم مدل‌ها
- 🎛️ پیکربندی زنده برای رم، حافظه و رنگ
- 💰 جمع قیمت که با هر انتخاب عوض می‌شود
- 🔝 دکمه بازگشت به بالا
- 🇮🇷 چیدمان RTL و رابط فارسی
- 📱 رابط واکنش‌گرا

# 🎨 نکات رابط

### لپ‌تاپی که با اسکرول باز می‌شود

هیرو یک عکس ثابت نیست. وقتی صفحه پایین می‌رود، درب لپ‌تاپ بالا می‌آید، صفحه نمایش مرکز توجه می‌شود و صحنه مثل رونمایی محصول حس می‌شود.

### مرحله‌های محصول

صفحه از آغاز به مدل‌ها، مشخصات، مقایسه و پیکربندی می‌رسد. ناوبری بین این مرحله‌ها جابه‌جا می‌شود بدون اینکه حرکت بشکند.

### پیکربندی محصول

رم، حافظه و رنگ همان‌جا عوض می‌شوند. برچسب‌ها و مبلغ کل فوری به‌روز می‌شوند تا دستگاه در حال ساخت دیده شود.

### جزئیات آرام

بعد از اسکرول هدر جمع‌وجور می‌شود، نوار پیشرفت نازک می‌ماند و لایهٔ دانه نمی‌گذارد صفحه تخت دیده شود.

# 📁 ساختار پروژه

```text
Electronics-Business-Website/
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
```

- `index.html` — اسکلت صفحه، بخش‌ها و کتابخانه‌های CDN
- `css/style.css` — چیدمان، رنگ و حرکت رابط
- `js/main.js` — GSAP، ScrollTrigger، صحنه Three.js، کانفیگوراتور و رفتار UI

کتابخانه‌های خارجی صفحه:

- Vazirmatn و JetBrains Mono
- GSAP و ScrollTrigger
- Three.js

https://sadra-hatami.github.io/Electronics-Business-Website/

### اجرای محلی

```bash
git clone https://github.com/sadra-hatami/Electronics-Business-Website.git
cd Electronics-Business-Website
python3 -m http.server 8080
```

بعد `http://localhost:8080` را باز کنید.
